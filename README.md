# Fleet MC Training
A static learning manual built with HTML, CSS, and vanilla JavaScript. No build tools, database, authentication, analytics, cookies, or browser storage.

## Run
From this directory: `python3 -m http.server 8000`. Open the server in a browser. JSON content requires HTTP rather than opening index.html directly. Deploy the directory to any static host; all internal paths are relative.

## Contents
Eight modules, 18 lessons from the supplied PDF, 51 glossary definitions, module keyword search and category filters, five practice questions with explanations, and hash-based direct links with browser history. Practice answers only live in memory. Responsive layout, keyboard focus, and reduced-motion support.

## Sources and scope
See docs/source-map.md and assets/manifest.json. Both supplied Markdown briefs were read as reference material. The user's requested name and no-storage requirement override their conflicting branding and persistence suggestions. The 33-gallery encyclopedia is a potential expansion, not represented as completed in this manual. Two other PDFs mentioned by the briefs were not supplied. Text is educational and not independently validated current legal/OEM guidance. Extracted PDF illustrations are used as editorial thumbnails only; rights for independent redistribution and embedded technical labels remain unverified.

Fonts use Google Fonts with system fallbacks. No JavaScript dependency or external image request is needed.
